# ردیاب عادت‌ها و کارهای یک‌روزه
رابط فارسی از بخش وب APK بازسازی شده است. پوشهٔ اندروید هنگام ساخت با Capacitor ایجاد می‌شود. برای استفاده، نیازی به Android Studio نیست.

## ساخت در GitHub
۱. ZIP را باز کنید. محتویات آن را در ریشهٔ شاخهٔ پیش‌فرض یک مخزن جدید قرار دهید، نه خود ZIP را. فایل `package.json` باید در صفحه اول مخزن دیده شود.
۲. مطمئن شوید `.github/workflows/android.yml` هم منتقل شده است. اگر آپلود مرورگر پوشهٔ مخفی را رد کرد، با **Add file → Create new file** همین مسیر کامل را وارد کنید، محتوای فایل را کپی کنید و Commit بزنید.
۳. در تب **Actions**، اگر لازم بود اجرای workflowها را فعال کنید. **Build Android APK → Run workflow** را بزنید. برای اولین تست، تیک نصب جداگانه روشن بماند.
۴. بعد از سبز شدن اجرا، در صفحهٔ همان اجرا و قسمت **Artifacts**، فایل `habit-tracker-apk` را بگیرید و از ZIP خارج کنید. فایل نصب `app-debug.apk` است.

## اطلاعات و امضا
نصب جداگانه شناسهٔ متفاوت دارد؛ اطلاعات قبلی را تغییر نمی‌دهد و خودکار هم نمی‌خواند. برای انتقال، در برنامهٔ قبلی پشتیبان JSON بگیرید، وجود آن را بررسی کنید و در برنامهٔ جدید بازیابی کنید. برنامهٔ قبلی را تا بررسی اطلاعات حذف نکنید.

برای نصب روی نسخهٔ قبلی، تیک نصب جداگانه باید خاموش باشد و امضای APK با نسخهٔ نصب‌شده یکسان باشد. برای ساخت‌های تکراری نیز کلید امضا باید ثابت بماند. اگر کلید دیباگ استاندارد قبلی را دارید (alias: androiddebugkey، رمز پیش‌فرض android)، محتوای Base64 آن را فقط در GitHub Actions Secret با نام `ANDROID_DEBUG_KEYSTORE_BASE64` قرار دهید، نه در مخزن. اگر این Secret تنظیم نشود، محیط ساخت کلید موقت ایجاد می‌کند. این workflow برای APK دیباگ طراحی شده نه انتشار فروشگاهی.

## تغییرات
در «امروز» یا «تقویم»، برای یک تاریخ کار اضافه کنید، تیک بزنید یا حذف کنید. این کارها تکرار نمی‌شوند و در آمار عادت‌ها وارد نمی‌شوند. پشتیبان JSON شامل هر دو نوع اطلاعات است. فایل اصلی رابط: `www/index.html`.
